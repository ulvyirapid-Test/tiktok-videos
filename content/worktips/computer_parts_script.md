# Script វីដេអូ៖ ផ្នែកនីមួយៗរបស់កុំព្យូទ័រ ធ្វើអ្វី? ដំណើរការយ៉ាងម៉េច?

**ស៊េរី:** កុំព្យូទ័រដំណើរការយ៉ាងម៉េច? · **គណនី:** @ulvyi · **ទម្រង់:** 9:16, Avatar + សំឡេង AI ខ្មែរ (Piseth) + គំនូរចលនា
**អ្នកមើល:** អ្នកប្រើកុំព្យូទ័ររាល់ថ្ងៃ (បុគ្គលិកការិយាល័យ សិស្ស) ដែលមិនមែនជាអ្នកជំនាញ
**ទម្រង់ស៊េរី (ស្នើ):** ចែកជា **២ ភាគ** ព្រោះមាន ៧ ផ្នែក ហើយត្រូវពន្យល់ឱ្យច្បាស់
- **ភាគ ១: ផ្នែកនីមួយៗធ្វើអ្វី?** (PSU, Motherboard, CPU, RAM, ROM, SSD, GPU) · ប្រហែល ២ នាទី
- **ភាគ ២: វាធ្វើការជាមួយគ្នាយ៉ាងម៉េច?** (ពីការចុចប៊ូតុងបើក ដល់ការបើកកម្មវិធី) · ប្រហែល ១ នាទី ៤៥ វិនាទី

**គំនិតសំខាន់ (ឧទាហរណ៍ប្រៀបធៀប):** កុំព្យូទ័រ = **ឃ្លាំងទំនិញមួយ**

| ផ្នែក | ក្នុងឃ្លាំង | តួនាទីពិត |
|---|---|---|
| **PSU** (ប្រភពថាមពល) | រោងចក្រអគ្គិសនីរបស់ឃ្លាំង | បំលែងភ្លើង 220V ពីជញ្ជាំង ទៅជាភ្លើងតូចៗ (12V, 5V, 3.3V) |
| **Motherboard** | ផ្លូវ និងខ្សែក្រវាត់ដឹកទំនិញ | ភ្ជាប់គ្រប់ផ្នែក និងបញ្ជូនទិន្នន័យ និងថាមពល |
| **CPU** | អ្នកគ្រប់គ្រងឃ្លាំង | អាន និងប្រតិបត្តិពាក្យបញ្ជា (Instructions) |
| **RAM** | តុធ្វើការ | ទុកទិន្នន័យដែលកំពុងប្រើ (លឿន តែបាត់ពេលបិទម៉ាស៊ីន) |
| **ROM** (BIOS/UEFI) | ក្រដាស SOP បិទនៅមាត់ទ្វារ | កម្មវិធីតូចដំបូងគេ ដែលដាស់កុំព្យូទ័រ |
| **SSD / HDD** | ធ្នើរទុកទំនិញ | ទុកឯកសារ និងកម្មវិធី រហូត (មិនបាត់ពេលបិទ) |
| **GPU** | ក្រុមអ្នកគូររូប | គូររូបភាពលើអេក្រង់ ដោយធ្វើការច្រើនក្នុងពេលតែមួយ |

# ភាគ ១: ផ្នែកនីមួយៗធ្វើអ្វី?

> **សំឡេង** = អ្វីដែល AI និយាយ · **អេក្រង់** = អក្សរធំ · **រូបភាព** = គំនូរ/ចលនា

### អេក្រង់ ១ · Hook
- **អេក្រង់:** កុំព្យូទ័រ = **ឃ្លាំងទំនិញ** 🏭 · ៧ ផ្នែក ៧ តួនាទី
- **រូបភាព:** Avatar + រូបកុំព្យូទ័របើកគម្រប ផ្នែកនីមួយៗលោតចេញមកម្តងមួយ
- **សំឡេង:** «តើអ្នកដឹងទេថា នៅក្នុងកុំព្យូទ័ររបស់អ្នក មានក្រុមការងារប្រាំពីរ ដែលធ្វើការជាមួយគ្នា ដូចឃ្លាំងទំនិញមួយ? ថ្ងៃនេះ ខ្ញុំនឹងពន្យល់ថា ផ្នែកនីមួយៗធ្វើអ្វី ហើយដំណើរការយ៉ាងម៉េច។»

### អេក្រង់ ២ · PSU (ប្រភពថាមពល)
- **អេក្រង់:** ១. **PSU** = រោងចក្រអគ្គិសនី ⚡ · 220V → 12V · 5V · 3.3V
- **រូបភាព:** ខ្សែភ្លើងពីជញ្ជាំង → ប្រអប់ PSU → ខ្សែបែកជាច្រើនទៅផ្នែកនីមួយៗ, ចរន្តភ្លឺហូរ
- **សំឡេង:** «ផ្នែកទីមួយ គឺ PSU ឬប្រភពថាមពល។ ភ្លើងពីជញ្ជាំងនៅកម្ពុជា មានកម្លាំង ពីររយម្ភៃវ៉ុល ដែលខ្លាំងពេកសម្រាប់គ្រឿងបន្លាស់កុំព្យូទ័រ។ PSU បំលែងវាទៅជាភ្លើងតូចៗ ដូចជា ដប់ពីរវ៉ុល ប្រាំវ៉ុល និងបីក្បៀសបីវ៉ុល ហើយចែកឱ្យផ្នែកនីមួយៗ។ គ្មាន PSU ផ្នែកផ្សេងទៀតមិនអាចដំណើរការបានទេ។»

### អេក្រង់ ៣ · Motherboard
- **អេក្រង់:** ២. **Motherboard** = ផ្លូវ + ខ្សែក្រវាត់ដឹកទំនិញ 🛣️
- **រូបភាព:** ផែនទី Motherboard: រន្ធ CPU, រន្ធ RAM, រន្ធ GPU, រន្ធ SSD · ពន្លឺទិន្នន័យរត់តាមផ្លូវ
- **សំឡេង:** «ផ្នែកទីពីរ គឺ Motherboard។ វាជាបន្ទះធំ ដែលផ្នែកទាំងអស់ដោតភ្ជាប់ ដូចផ្លូវ និងខ្សែក្រវាត់ក្នុងឃ្លាំង ដែលភ្ជាប់គ្រប់តំបន់។ Motherboard មានរន្ធសម្រាប់ CPU, RAM, GPU និង SSD ហើយមានខ្សែស្ពាន់តូចៗរាប់ពាន់ ដែលបញ្ជូនទិន្នន័យ និងថាមពលទៅគ្នាទៅវិញទៅមក។»

### អេក្រង់ ៤ · CPU
- **អេក្រង់:** ៣. **CPU** = អ្នកគ្រប់គ្រងឃ្លាំង 🧠 · យក → បកប្រែ → ធ្វើ
- **រូបភាព:** ឈីប CPU, វដ្តបីជំហានវិលជុំ (Fetch → Decode → Execute), លេខ «GHz» រាប់ឡើង, Cores ៤ ធ្វើការស្របគ្នា
- **សំឡេង:** «ផ្នែកទីបី គឺ CPU ដែលជាខួរក្បាល ឬអ្នកគ្រប់គ្រងឃ្លាំង។ CPU ធ្វើការងារបីជំហាន ម្តងហើយម្តងទៀត។ ដំបូង យកពាក្យបញ្ជាមួយ។ បន្ទាប់មក បកប្រែថាត្រូវធ្វើអ្វី។ រួចធ្វើវា ដូចជាបូកលេខ ឬផ្លាស់ទីទិន្នន័យ។ ល្បឿនរបស់ CPU វាស់ជា GHz ឧទាហរណ៍ បី GHz មានន័យថា បីពាន់លានចង្វាក់ក្នុងមួយវិនាទី។ ហើយ CPU សព្វថ្ងៃមានស្នូលច្រើន ដែលហៅថា Cores ដូចមានអ្នកគ្រប់គ្រងច្រើននាក់ ធ្វើការក្នុងពេលតែមួយ។»

### អេក្រង់ ៥ · RAM
- **អេក្រង់:** ៤. **RAM** = តុធ្វើការ 🗂️ · លឿន · បាត់ពេលបិទម៉ាស៊ីន
- **រូបភាព:** តុធ្វើការ: ឯកសារកម្មវិធីដែលកំពុងបើកត្រូវដាក់លើតុ, ពេលបិទម៉ាស៊ីន តុទទេ · បន្ទះ RAM «8GB / 16GB»
- **សំឡេង:** «ផ្នែកទីបួន គឺ RAM ដែលជាតុធ្វើការ។ ពេលអ្នកបើកកម្មវិធី ឬឯកសារ កុំព្យូទ័រយកវាមកដាក់លើតុ RAM ដើម្បីឱ្យ CPU ប្រើបានលឿន។ RAM លឿនជាង SSD ច្រើនដង ប៉ុន្តែវាជាអង្គចងចាំបណ្តោះអាសន្ន ពេលបិទម៉ាស៊ីន អ្វីៗលើតុបាត់អស់។ ហេតុនេះហើយ បើយើងមិន Save ឯកសារ ពេលភ្លើងដាច់ ការងារនឹងបាត់។ RAM កាន់តែធំ យើងបើកកម្មវិធីបានកាន់តែច្រើនក្នុងពេលតែមួយ។»

### អេក្រង់ ៦ · ROM (BIOS / UEFI)
- **អេក្រង់:** ៥. **ROM** = ក្រដាស SOP នៅមាត់ទ្វារ 📋 · BIOS / UEFI
- **រូបភាព:** ឈីបតូចលើ Motherboard មានស្លាក «BIOS/UEFI», បញ្ជីពិនិត្យ ✔ RAM ✔ SSD ✔ Keyboard
- **សំឡេង:** «ផ្នែកទីប្រាំ គឺ ROM។ នៅក្នុងកុំព្យូទ័រ វាជាឈីបតូចមួយលើ Motherboard ដែលផ្ទុកកម្មវិធីឈ្មោះ BIOS ឬ UEFI។ ដូចក្រដាស SOP បិទនៅមាត់ទ្វារឃ្លាំង ដែលប្រាប់ថា ពេលបើកទ្វារព្រឹក ត្រូវពិនិត្យអ្វីខ្លះមុន។ វាមិនបាត់ទេ ពេលបិទម៉ាស៊ីន។ ចំណាំ៖ នៅលើទូរស័ព្ទ ពាក្យ ROM មួយរយម្ភៃប្រាំបី ជីកាបៃ ជាធម្មតាមានន័យថា កន្លែងផ្ទុកទិន្នន័យ មិនមែន ROM ពិតប្រាកដនេះទេ។»

### អេក្រង់ ៧ · SSD / HDD
- **អេក្រង់:** ៦. **SSD / HDD** = ធ្នើរទុកទំនិញ 📦 · ទុករហូត
- **រូបភាព:** ធ្នើរ: ឯកសារ រូបថត កម្មវិធី Windows ត្រូវបានទុក, ប្រៀបធៀប HDD (ថាសវិល) និង SSD (ឈីប) ល្បឿន
- **សំឡេង:** «ផ្នែកទីប្រាំមួយ គឺ SSD ឬ HDD ដែលជាធ្នើរទុកទំនិញ។ វាទុក Windows កម្មវិធី រូបថត និងឯកសារទាំងអស់ ហើយមិនបាត់ទេពេលបិទម៉ាស៊ីន។ HDD ប្រើថាសមេដែកវិល ហើយយឺតជាង។ SSD ប្រើឈីប Flash គ្មានផ្នែកកម្រើក ហើយលឿនជាងច្រើន ហេតុនេះកុំព្យូទ័រដែលមាន SSD បើកបានលឿន។ តែ SSD នៅតែយឺតជាង RAM ដូច្នេះអ្វីដែលកំពុងប្រើ ត្រូវយកមកដាក់លើតុ RAM មុន។»

### អេក្រង់ ៨ · GPU
- **អេក្រង់:** ៧. **GPU** = ក្រុមអ្នកគូររូប 🎨 · Cores រាប់ពាន់
- **រូបភាព:** CPU = អ្នកជំនាញ ៨ នាក់ / GPU = អ្នកធ្វើការរាប់ពាន់នាក់ ពណ៌ភីកសែលព្រមៗគ្នា

## ការពិនិត្យការពិត (Fact check)
**បានផ្ទៀងផ្ទាត់:**
- **PSU**: បំលែងភ្លើង AC ពីជញ្ជាំង (កម្ពុជា 220–230V) ទៅជា DC 12V, 5V, 3.3V ✔️
- **CPU**: វដ្ត Fetch → Decode → Execute ✔️ · 3 GHz = 3 ពាន់លានចង្វាក់/វិនាទី ✔️ · Cores ច្រើន ធ្វើការស្របគ្នា ✔️
- **RAM**: Volatile (បាត់ពេលគ្មានភ្លើង), លឿនជាង SSD ច្រើន ✔️
- **SSD vs HDD**: HDD = ថាសមេដែកវិល, SSD = Flash គ្មានផ្នែកកម្រើក, លឿនជាង ✔️ · SSD យឺតជាង RAM ✔️
- **GPU**: Cores រាប់ពាន់ សម្រាប់ការងារស្របគ្នា (Parallel) ✔️ · មាន GPU រួមក្នុង CPU (Integrated) និងកាតដាច់ (Dedicated) ✔️
- **Boot**: PSU → Firmware (BIOS/UEFI) → POST → រក Boot drive → ផ្ទុក OS ចូល RAM ✔️ · POST error អាចបន្លឺសំឡេងប៊ីប ✔️ (ម៉ាស៊ីនខ្លះ)
- **Save**: ចម្លងទិន្នន័យពី RAM ទៅ Storage ✔️

**ការធ្វើឱ្យសាមញ្ញ (ដោយចេតនា):**
- **ROM**: នៅក្នុងកុំព្យូទ័រសព្វថ្ងៃ BIOS/UEFI ទុកក្នុងឈីប **Flash** ដែលអាច Update បាន មិនមែន ROM «អានបានតែប៉ុណ្ណោះ» ពិតប្រាកដទេ។ ប៉ុន្តែគេនៅតែហៅថា ROM BIOS ហើយតួនាទីដូចគ្នា (មិនបាត់ពេលបិទ, ដំណើរការដំបូងគេ)។ script ប្រើពាក្យ «ឈីប ROM» ដើម្បីភ្ជាប់នឹងពាក្យដែលអ្នកមើលស្គាល់
- **ROM លើទូរស័ព្ទ**: ពាក្យ «ROM 128GB» ក្នុងការលក់ទូរស័ព្ទ ជាធម្មតាមានន័យថា Storage ✔️ (script បញ្ជាក់ច្បាស់)
- **CPU ក៏មាន Cache** (អង្គចងចាំលឿនជាង RAM) តែមិនបានលើកឡើង ដើម្បីកុំឱ្យស្មុគស្មាញ
- **Windows** ផ្ទុកតែផ្នែកដែលត្រូវការចូល RAM មិនមែនទាំងមូលទេ (script និយាយថា «ផ្នែកសំខាន់ៗ»)
- **Motherboard** ចែកភ្លើងបន្តមួយភាគ ខ្លះទៀតមានខ្សែពី PSU ទៅផ្ទាល់ (ឧ. GPU ធំៗ)
