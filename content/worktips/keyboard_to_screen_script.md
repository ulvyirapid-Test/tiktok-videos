# Script វីដេអូ៖ ពីការចុច Keyboard ដល់អក្សរលើ Screen

**ស៊េរី:** កុំព្យូទ័រដំណើរការយ៉ាងម៉េច? · **គណនី:** @ulvyi · **ទម្រង់:** 9:16, Avatar + សំឡេង AI ខ្មែរ (Piseth)
**រយៈពេល:** ប្រហែល ១ នាទី ៤៥ វិនាទី · **អ្នកមើល:** អ្នកដែលប្រើកុំព្យូទ័ររាល់ថ្ងៃ តែមិនដឹងថាវាដំណើរការយ៉ាងម៉េច

**សារសំខាន់:** ពេលយើងចុចអក្សរ A មួយ វាធ្វើដំណើរ **១០ ដំណាក់កាល** ពីចរន្តអគ្គិសនី → លេខ 0/1 → អក្សរ → ភីកសែល ហើយទាំងអស់នេះកើតឡើង**លឿនជាងការព្រិចភ្នែក** (ជាធម្មតាប្រហែល ០.០៣–០.១ វិនាទី)។

## ផែនទីដំណើរ ១០ ដំណាក់កាល

| # | ដំណាក់កាល | ឧបករណ៍ | អក្សរ A ក្លាយជា |
|---|---|---|---|

## Script ពេញ (១២ អេក្រង់)

> **សំឡេង** = អ្វីដែល AI និយាយ (ពាក្យអង់គ្លេសនឹងអានជាខ្មែរដោយស្វ័យប្រវត្តិ)
> **អេក្រង់** = អក្សរធំលើវីដេអូ · **រូបភាព** = គំនូរ/ចលនា

### អេក្រង់ ១ · Hook (០:០០)
- **អេក្រង់:** ចុច **A** មួយដង… ធ្វើដំណើរ **១០ ដំណាក់កាល** ⚡
- **រូបភាព:** Avatar + គ្រាប់ចុច A ចុះឡើង, លេខ 0101 ហោះចេញ
- **សំឡេង:** «ពេលអ្នកចុចអក្សរ A មួយដងលើ Keyboard តើអ្នកដឹងទេថា វាធ្វើដំណើរដប់ដំណាក់កាល មុននឹងបង្ហាញលើអេក្រង់? ហើយទាំងអស់នេះ កើតឡើងលឿនជាងការព្រិចភ្នែករបស់អ្នកទៅទៀត។»

### អេក្រង់ ២ · ចុចគ្រាប់ចុច (Switch)
- **អេក្រង់:** ១. ចុចគ្រាប់ចុច = **បិទសៀគ្វី** 🔌
- **រូបភាព:** គ្រាប់ចុចកាត់ទទឹង: Switch ពីរបន្ទះប៉ះគ្នា, ចរន្តហូរ
- **សំឡេង:** «ដំណាក់កាលទីមួយ។ នៅក្រោមគ្រាប់ចុចនីមួយៗ មាន Switch តូចមួយ។ ពេលអ្នកចុច Switch ប៉ះគ្នា ហើយចរន្តអគ្គិសនីហូរកាត់។ ពេលលែងដៃ ចរន្តឈប់។ មានចរន្ត និងគ្មានចរន្ត នេះហើយជាប្រភពនៃលេខមួយ និងលេខសូន្យ។»

### អេក្រង់ ៣ · Chip ស្កេន Keyboard
- **អេក្រង់:** ២. Chip ស្កេនរាប់រយ ទៅរាប់ពាន់ដង / វិនាទី 🔍
- **រូបភាព:** ក្រឡាចត្រង្គ (ជួរដេក × ជួរឈរ), ចំណុចមួយភ្លឺត្រង់ A
- **សំឡេង:** «ដំណាក់កាលទីពីរ។ គ្រាប់ចុចទាំងអស់ ត្រូវបានតភ្ជាប់ជាក្រឡាចត្រង្គ ជួរដេក និងជួរឈរ។ Chip តូចមួយក្នុង Keyboard ស្កេនក្រឡានេះ រាប់រយ ទៅរាប់ពាន់ដងក្នុងមួយវិនាទី ដើម្បីដឹងថា គ្រាប់ចុចណាត្រូវបានចុច។»

### អេក្រង់ ៤ · Key Code + Binary
- **អេក្រង់:** ៣. A → Key code **4** → `00000100`
- **រូបភាព:** លេខ 4 បំលែងជាប្រអប់ ៨ (Bits) ភ្លឺ/មិនភ្លឺ
- **សំឡេង:** «ដំណាក់កាលទីបី។ Chip បំលែងគ្រាប់ចុចទៅជាលេខកូដ។ សម្រាប់ Keyboard USB គ្រាប់ចុច A មានលេខកូដ បួន។ តែកុំព្យូទ័រស្គាល់តែលេខសូន្យ និងមួយ ដូច្នេះលេខបួន ត្រូវសរសេរជា Binary ប្រាំបីខ្ទង់។ ប្រាំបីខ្ទង់នេះ ហៅថា មួយ Byte។ Keyboard ផ្ញើលេខកូដនេះ ក្នុងកញ្ចប់ទិន្នន័យតូចមួយ ដែលប្រាប់ផងដែរថា តើអ្នកកំពុងសង្កត់ Shift ឬទេ។ ចំណាំ៖ នៅដំណាក់កាលនេះ វានៅជាទីតាំងគ្រាប់ចុចប៉ុណ្ណោះ មិនទាន់ជាអក្សរ A ទេ។»

### អេក្រង់ ៥ · ផ្ញើតាមខ្សែ USB
- **អេក្រង់:** ៤. ផ្ញើតាមខ្សែ **USB** ⚡⚡
- **រូបភាព:** ខ្សែ USB មានខ្សែទិន្នន័យពីរ (D+ និង D−), សញ្ញាលោតឆ្លាស់គ្នា ហូរទៅ Motherboard
- **សំឡេង:** «ដំណាក់កាលទីបួន។ លេខសូន្យ និងមួយទាំងនោះ ធ្វើដំណើរតាមខ្សែ USB ជាសញ្ញាអគ្គិសនី នៅលើខ្សែទិន្នន័យពីរ ដែលផ្លាស់ប្តូរឆ្លាស់គ្នាលឿនបំផុត។ ការផ្លាស់ប្តូរ ឬមិនផ្លាស់ប្តូរនៃសញ្ញា តំណាងឱ្យលេខសូន្យ និងមួយ។ ហើយកុំព្យូទ័រ សួរ Keyboard ជាប់ៗគ្នា រាប់រយដងក្នុងមួយវិនាទី ថាតើមានគ្រាប់ចុចថ្មីទេ។»

### អេក្រង់ ៦ · CPU ទទួល (Interrupt)
- **អេក្រង់:** ៥. CPU៖ «មានគ្រាប់ចុចថ្មី!» 🧠
- **រូបភាព:** Chip CPU, សញ្ញាពណ៌ក្រហមលោតចូល
- **សំឡេង:** «ដំណាក់កាលទីប្រាំ។ USB Controller នៅលើ Motherboard ទទួលទិន្នន័យ ហើយផ្ញើសញ្ញាប្រាប់ CPU ថា មានគ្រាប់ចុចថ្មី។ CPU ឈប់ការងារផ្សេងមួយភ្លែត ដើម្បីដោះស្រាយវាភ្លាម។»

### អេក្រង់ ៧ · Driver + Layout → អក្សរ
- **អេក្រង់:** ៦. Key **4** + Layout English → **a = 97** = `01100001` · + Shift → **A = 65** = `01000001`
- **រូបភាព:** ប្រអប់ Windows/macOS, ប្តូរ Layout EN ↔ KH: Key 4 → «A» ឬ អក្សរខ្មែរ
- **សំឡេង:** «ដំណាក់កាលទីប្រាំមួយ។ Driver ក្នុងប្រព័ន្ធប្រតិបត្តិការ ដូចជា Windows មើល Keyboard Layout ដែលអ្នកកំពុងប្រើ។ បើជាភាសាអង់គ្លេស ហើយមិនសង្កត់ Shift លេខកូដបួន ក្លាយជាអក្សរ a តូច ដែលមានលេខកូដ Unicode កៅសិបប្រាំពីរ។ បើសង្កត់ Shift វាក្លាយជាអក្សរ A ធំ ដែលមានលេខកូដហុកសិបប្រាំ ឬ Binary សូន្យមួយសូន្យសូន្យ សូន្យសូន្យសូន្យមួយ។ បើអ្នកប្តូរទៅ Keyboard ខ្មែរ គ្រាប់ចុចដដែល អាចក្លាយជាអក្សរខ្មែរ។ នេះហើយជាមូលហេតុ ដែលគ្រាប់ចុចមួយ វាយបានពីរភាសា។»

### អេក្រង់ ៨ · កម្មវិធី + RAM
- **អេក្រង់:** ៧. កម្មវិធីរក្សាទុកក្នុង **RAM** 💾
- **រូបភាព:** បន្ទះ RAM, ប្រអប់ Byte «01000001» ធ្លាក់ចូល
- **សំឡេង:** «ដំណាក់កាលទីប្រាំពីរ។ កម្មវិធីដែលអ្នកកំពុងវាយ ដូចជា Word ឬ Chrome ទទួលអក្សរ A ហើយរក្សាទុកក្នុង RAM ដែលជាអង្គចងចាំបណ្តោះអាសន្ន។ ពេលនេះ អក្សរ A នៅជាលេខ ហើយមិនទាន់មានរូបរាងនៅឡើយទេ។»

### អេក្រង់ ៩ · Font → ភីកសែល
- **អេក្រង់:** ៨. **Font** គូររូបអក្សរ ✏️
- **រូបភាព:** អក្សរ A គូរជាគ្រោងខ្សែ រួចបំពេញជាក្រឡាភីកសែល
- **សំឡេង:** «ដំណាក់កាលទីប្រាំបី។ ដើម្បីបង្ហាញ កុំព្យូទ័របើក Font ដើម្បីរករូបរាងរបស់អក្សរ A។ Font ផ្ទុកគ្រោងរបស់អក្សរនីមួយៗ ហើយកុំព្យូទ័របំលែងគ្រោងនោះ ទៅជាចំណុចតូចៗ ដែលហៅថា ភីកសែល។»

### អេក្រង់ ១០ · កាតក្រាហ្វិក (GPU)
- **អេក្រង់:** ៩. **កាតក្រាហ្វិក** បង្កើតរូបភាពពេញអេក្រង់ 🎨

## ការពិនិត្យការពិត (Fact check) — កែប្រែលើកទី ២
**ចំណុចដែលបានកែ:**
- ❌→✅ **ចុច A ធម្មតា = a តូច (៩៧ = 01100001)** មិនមែន A ធំទេ។ A ធំ (៦៥ = 01000001) ត្រូវការ Shift ឬ Caps Lock
- ❌→✅ **USB មិនមែន «ចរន្តខ្ពស់ = 1, ទាប = 0»** ទេ។ USB ប្រើខ្សែទិន្នន័យពីរ (D+ / D−) ហើយលេខ 0/1 តំណាងដោយការផ្លាស់ប្តូរ ឬមិនផ្លាស់ប្តូរនៃសញ្ញា (NRZI)
- ❌→✅ **«តិចជាង ១/១០ វិនាទី» មិនពិតគ្រប់ម៉ាស៊ីនទេ**: ម៉ាស៊ីនខ្លះយឺតជាងនេះ។ ឥឡូវប្រើ «លឿនជាងការព្រិចភ្នែក» ដែលត្រឹមត្រូវជាង
- ⚠️→✅ Chip ស្កេន «រាប់រយ ទៅរាប់ពាន់ដង» (មុនថា «រាប់រយ»)
- ⚠️→✅ Keyboard ផ្ញើ**កញ្ចប់ទិន្នន័យ** (មានលេខកូដគ្រាប់ចុច + ស្ថានភាព Shift/Ctrl) មិនមែនលេខតែមួយ Byte ទេ
