# tiktok-videos

Khmer tech-news TikTok videos (9:16), generated by Claude and posted via Metricool.

- `content/YYYY-MM-DD.json` — script for one video (hook, tag, headline, 3 facts, why, source, caption, title)
- `generator/make_news_video.py content/X.json videos/X.mp4 SEED` — renders the video with original background music
- `videos/` — public MP4s that Metricool pulls from `raw.githubusercontent.com`
- Font: Kantumruy Pro (SIL Open Font License)

## Smart Tips KH daily shorts

Brand: Smart Tips KH (navy / yellow / cyan, lightbulb logo). One short per day, Mon–Thu tips + Fri tech news, 30–45 s, Khmer on-screen text.

- `content/smarttips/YYYY-MM-DD-day-slug.json` — scene spec (topic, scenes with icon, main, sub, number, accent, glow, note, pill, seconds)
- `python3 generator/smarttips/build_short.py SPEC.json videos/smarttips/NAME.mp4 SEED` — renders 1080×1920 video with original background music and writes `NAME_preview.png` (one frame per scene) for checking Khmer text; delete the preview before committing
- Icons: see `ICONS` in `build_short.py` (generic shapes only — no company logos)
- Rules: max 2 lines per `main`, ~22 Khmer chars per line; no ✓/✗ symbols (font lacks them); keep text left of the right 15% and above the bottom 20%
- `generator/make_news_carousel.py content/X.json carousels/X ACCENT` — renders the same script as a 7-slide photo carousel (JPG)
- `carousels/` — public JPG slides for TikTok photo posts

## Work-Tips series ("AI សម្រាប់ការងារ")
Animated shorts (chat typing, spreadsheet, phone alerts, flow, steps) rendered from JSON with `generator/worktips/engine.html`.
- Video: `python3 generator/worktips/render.py content/worktips/SPEC.json videos/OUT.mp4 MUSIC_SEED`
- Preview frames: `python3 generator/worktips/render.py content/worktips/SPEC.json --preview 0 5 12`
- Carousel: `python3 generator/worktips/render_slides.py content/worktips/SPEC.json carousels/OUT_DIR` (spec uses `slides`)
- Scene types: hook, compare, sheet, chat, phone, flow, steps, tip, prompt, cta. Markup: *cyan* _violet_ ~green~ !yellow!
