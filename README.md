# tiktok-videos

Khmer tech-news TikTok videos (9:16), generated by Claude and posted via Metricool.

- `content/YYYY-MM-DD.json` — script for one video (hook, tag, headline, 3 facts, why, source, caption, title)
- `generator/make_news_video.py content/X.json videos/X.mp4 SEED` — renders the video with original background music
- `videos/` — public MP4s that Metricool pulls from `raw.githubusercontent.com`
- Font: Kantumruy Pro (SIL Open Font License)
